# 🎯 Mock Interview Platform

An interactive **Mock Interview Application** designed to help students, freshers, and job seekers prepare for technical and HR interviews. The platform provides a simulated interview environment where users can practice answering questions, improve their communication skills, and build confidence before attending real-world interviews.

## 🚀 Features

- **User Authentication** – Secure registration and login.
- **Mock Interviews** – Practice interviews in a simulated environment.
- **Technical Interview Questions** – Prepare for programming, database, OOPs, and other technical topics.
- **HR Interview Preparation** – Practice commonly asked HR and behavioral questions.
- **Answer Evaluation** – Get feedback on your interview responses.
- **Interview History** – Track previous interview attempts and progress.
- **Responsive Design** – Accessible across desktop, tablet, and mobile devices.

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Mock-Interview.git
```

### 2. Navigate to the Project Directory

```bash
cd Mock-Interview
```

### 3. Install Dependencies

For the frontend:

```bash
cd frontend
npm install
```

For the backend:

```bash
cd ../backend
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the backend directory and add the required configuration:

```env
PORT=5000
DATABASE_URL=your_database_url
JWT_SECRET=your_secret_key
```

### 5. Run the Application

Start the backend:

```bash
npm run dev
```

Start the frontend in a separate terminal:

```bash
cd frontend
npm run dev
```

Open the local URL displayed in your terminal to access the application.
